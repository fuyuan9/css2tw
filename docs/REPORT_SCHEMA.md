# css2tw Report Schema Specification

This document defines the stable schema for the JSON reports generated by the `css2tw` CLI.

## Compatibility Policy

- **Semantic Versioning**: The `version` field in the report matches the tool version. Major version changes may include breaking schema modifications.
- **Backward Compatibility**: In minor and patch versions, we do not remove existing fields or change their types. New fields may be added in minor versions.
- **Enum Expansion**: Enums such as `FailureReason` and `ConfidenceReason` may have new values added in the future. Parsers should be robust against unknown values.

## Data Structures

### Report (Root Object)

| Field | Type | Description |
| :--- | :--- | :--- |
| `version` | `string` | The version of the report schema. |
| `command` | `string` | The command that generated the report (`scan`, `convert`). |
| `mode` | `string` | The execution mode (`read_only`, `dry_run`, `write`). |
| `summary` | `Summary` | Aggregate statistics of the conversion process. |
| `changes` | `Vec<ChangeFile>` | Detailed changes per file (only if changes exist). |
| `unconverted` | `Vec<Unconverted>` | Elements that could not be converted (only if failures exist). |
| `warnings` | `Vec<string>` | General warning messages. |
| `errors` | `Vec<string>` | Fatal error messages. |

### Summary

| Field | Type | Description |
| :--- | :--- | :--- |
| `files_scanned` | `number` | Total number of files scanned. |
| `css_files_scanned` | `number` | Total number of CSS files analyzed. |
| `source_files_scanned` | `number` | Total number of source files scanned for class usage. |
| `classes_found` | `number` | Total number of unique class names found. |
| `classes_convertible` | `number` | Number of classes that can be converted. |
| `classes_unconvertible` | `number` | Number of classes that cannot be converted. |
| `files_changed` | `number` | Number of files actually modified (or planned to be). |
| `replacements_planned` | `number` | Total number of individual replacements planned. |

### ChangeFile

| Field | Type | Description |
| :--- | :--- | :--- |
| `file` | `string` | Path to the file relative to the scan root. |
| `status` | `string` | File status (`found`, `planned`, `modified`, `streamed`). |
| `patches` | `Vec<ReplacementReport>` | Detailed list of patches (replacements) within this file. |
| `patched_content` | `string?` | The full content of the file after replacements (optional). |
| `diff` | `string?` | A unified diff string of the changes (optional). |

### Unconverted

| Field | Type | Description |
| :--- | :--- | :--- |
| `selector` | `string` | The original selector or class name. |
| `reason` | `FailureReason` | Category of the failure (see below). |
| `details` | `string` | Detailed explanation of the failure. |
| `confidence` | `number` | Confidence score (0.0 - 1.0). |
| `range` | `Range?` | Byte range in the source file. |
| `raw_css` | `string?` | The original CSS declarations that could not be mapped. |

## Enums

### FailureReason

Categories used by AI agents to determine fallback strategies.

- `ComplexSelector`: The selector is too complex to resolve accurately (e.g., complex pseudo-elements).
- `UnsupportedProperty`: CSS properties that do not map to Tailwind utilities or are currently unsupported.
- `AmbiguousCascade`: Conflicting rules where the final state cannot be determined safely.
- `RequiresThemeToken`: Values that require custom theme configuration.
- `DynamicClass`: Class names that appear to be dynamically generated.
- `UnsafeSpecificity`: Conversion risks changing CSS specificity behavior.
- `NoMappingFound`: Default reason when no utility mapping is found.

### ConfidenceReason

- `FullMatch`: Exact match to standard utilities.
- `PartialMatch`: Some properties use arbitrary values (`[...]`).
- `AmbiguousSelector`: Multiple selectors matched the element.
- `VariableResolved`: CSS variables were successfully resolved.
- `ThemeMapping`: Matched custom theme tokens.
- `ArbitraryValue`: An arbitrary value utility was generated.
- `LowConfidenceProperty`: Includes properties with low mapping confidence.
