# Security Policy

## Supported Versions

Currently, only the latest version of `css2tw` is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please **do not** open a public issue. Instead, please use the [GitHub Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidelines-for-reporting-a-security-vulnerability-to-a-repository) feature if available.

If that is not available, please contact the maintainer via GitHub issues or other public channels to request a private communication channel.

We take all security reports seriously and will respond as quickly as possible.
